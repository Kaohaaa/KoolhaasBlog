# Koolhaas' Blog

This is a web project made by Koolhaas as his own Blog. 

You may have met this old  [考哈的 Blog](https://kaohaaa.github.io) before. And this project is to rewrite it with Vue and improve my own develop abilities. 

You can change it to your own blog with several simple steps: 

1. Fork the respository. 

2. Modify `ownerNme` to your name in `zh-CN.json` and other language files. 

3. Replace some picture in `public` and `images` to make. 

That's all, good luck!
